ガウシアンビーム半径計算機

ビームウエストから指定した距離における理想ガウシアンビームの半径を計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

負・0・正の値

SI 単位への換算後に 0 より大きい値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

強度が 1/e² になるビーム半径 w(z)

—

値を入力し「計算する」を押してください。

公式

w(z) = w₀√[1+(z/z_R)²], z_R=πnw₀²/λ₀

適用条件

λ₀,w₀,n>0、z は符号付きとします。半径は強度が軸上の 1/e² になる位置です。一様・等方・線形・無損失媒質内の基本 TEM₀₀ モードで M²=1 を仮定します。レンズ、開口、非線形伝搬は考慮しません。近軸条件 λ₀/(πnw₀)≤0.1 rad が必要です。真空波長を入力し、屈折率は内部で適用します。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
